# Workflow: Post with Gemini-Generated Image

## Steps

1. **Generate image** — Open gemini.google.com in Chrome, type image prompt
2. **Download** — Click download button on the generated image
3. **Remove watermark** — Crop out Gemini logo/watermark from bottom of image
4. **Compose tweet** — Navigate to x.com, compose tweet with text
5. **Attach image** — Upload the cropped image via the media button
6. **Post** — Click the Post/Đăng button

## Prompt Templates

### Bear Market Survivor
```
Generate an image: A cinematic meme-style photo showing 5 panels side by side. Each panel shows the same young man in a hoodie sitting at a desk with multiple trading monitors. Panel 1 (2022): stressed, red charts, "$69K". Panel 2 (2023): tired but holding, "$25K". Panel 3 (2024): calm, "$38K". Panel 4 (2025): confident, "$72K". Panel 5 (2026): celebrating, "$95K". Bottom text: "Bear market survivors always win." Dark moody lighting.
```

### Portfolio Loss Progression (used in first post)
```
Generate an image: 5 panels side by side showing the same girl in different outfits, same pose. Each panel has a price overlay showing declining values: $87,397, $80,915, $76,024, $74,261, $68,554. Bottom text: "Same girl. Same pose. Portfolio -21.6%." Clean photography style.
```

### Bull Run Excitement
```
Generate an image: 4 panels showing a man's reaction to crypto prices. Panel 1: checking phone casually at $50K. Panel 2: sitting up at $75K. Panel 3: standing excited at $100K. Panel 4: jumping with joy at $150K. Bottom text: "The bull run hits different when you survived the bear."
```

### Altcoin Season
```
Generate an image: Split image - left side shows a boring office worker at desk (labeled "9-5 Job"), right side shows same person on yacht with laptop (labeled "Altcoin Season"). Meme style, realistic photography.
```

## Notes
- Gemini watermark appears at bottom-right corner of images
- Crop ~20-30px from bottom to remove it cleanly
- Images work best at 16:9 or 1:1 ratio for X
- Always check image before posting — AI can make text errors
